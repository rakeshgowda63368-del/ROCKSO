# ROCKSO™ Store — Premium React Starter

A fully responsive, production-ready front-end storefront for ROCKSO, built with **React + Vite** and plain CSS.

## Brand Colours
| Token | Value | Usage |
|-------|-------|-------|
| Black | `#000000` | Primary, text, CTA |
| White | `#ffffff` | Reverse, backgrounds |
| Off-white | `#f7f6f3` | Page background |
| Dark | `#0a0a0a` | Hero, footer |
| Grey range | `#333–#aaa` | Borders, muted text |

## Included Features
- ✅ Responsive home page with ROCKSO identity
- ✅ Hero with animated full-screen image, stats strip
- ✅ Scrolling marquee brand strip
- ✅ Manifesto / brand story section
- ✅ Dual featured-category banner
- ✅ Product grid with **8 items** (T-Shirts, Hoodies, Bottoms, Jackets, Accessories)
- ✅ Category filter tabs
- ✅ **Quick-add modal** with size selector + validation
- ✅ **Wishlist** per product card
- ✅ **Cart drawer** with quantity controls, remove, free-shipping progress bar
- ✅ **Search overlay** with live filtering + keyboard shortcut `Ctrl/Cmd+K`
- ✅ Newsletter signup
- ✅ Instagram grid strip
- ✅ 4-perk trust bar
- ✅ Full footer with links, social, newsletter
- ✅ Cart persisted in `localStorage`
- ✅ Mobile nav (full-screen overlay)
- ✅ Scroll-aware sticky header

## Run Locally

1. Install Node.js (LTS) from https://nodejs.org
2. Open a terminal in this `rockso-store` folder
3. Run:

```bash
npm install
npm run dev
```

4. Open http://localhost:5173

## Build for Production

```bash
npm run build
```

Output is in `dist/`. Upload to Netlify, Vercel, or any static host.

## Before Launch Checklist
- [ ] Replace placeholder product images with real ROCKSO photos
- [ ] Update product names, prices, sizes and descriptions in `src/data/products.js`
- [ ] Integrate **Razorpay** (or Stripe) for payments — server-side only, never expose secret keys in frontend
- [ ] Add a backend / database for orders, customers and inventory
- [ ] Connect a real shipping provider (Shiprocket, Delhivery, etc.)
- [ ] Add GST invoicing, order confirmation SMS/email
- [ ] Add size guide, return/refund policy pages
- [ ] Set up Google Analytics or equivalent
- [ ] Test all pages on real mobile devices
